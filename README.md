# LendingClub Loan Charge-off Prediction

## Overview

This project uses machine learning to predict whether a LendingClub loan will be fully paid or charged off using borrower and loan listing data.

## Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature engineering
* Predictive modeling
* Model evaluation

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook
